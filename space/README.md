# ZORAX Nemotron Document Intelligence

This Space is a demonstration adapter for
`nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-NVFP4`.

Set `HF_TOKEN` as a Space secret to enable Hugging Face Inference Providers.
Without it, the demo returns clearly labeled synthetic output and does not
pretend to verify a bank instrument.
